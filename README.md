A Wi-Fi network name told in the router's own voice: "He left. I changed my password" — thirty characters that carry a whole breakup in two sentences, with the router itself delivering the petty final word by locking its former owner out of the network.

## How it works

`main.ts` writes the 30-character entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), checking first that it is within the 32-character limit.
